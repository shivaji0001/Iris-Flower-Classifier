# 🌸 Iris Flower Classifier

A beginner-friendly Machine Learning project that predicts the species of an Iris flower using four measurements.

## Features

The user provides:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The model predicts one of:

- Setosa
- Versicolor
- Virginica

## Technologies Used

- Python
- Scikit-learn
- Random Forest
- Streamlit
- Pickle
